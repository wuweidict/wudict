*[HTML]: The markup language of web pages, and of most dictionary articles
*[CSS]: The style language that gives HTML its look
*[UI]: User interface

*[RAM]: The computer's working memory

*[MB]: Megabyte

*[loopback]: The network address 127.0.0.1, which only your own machine can reach
